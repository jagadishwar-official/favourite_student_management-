# Favourite Student Management

A responsive React application for managing favourite students using React Router and the Context API.

## About the Project

Favourite Student Management is a React-based web application that allows users to view a list of students and add students to their favourites.

The application uses the React Context API to manage favourite students globally and React Router to navigate between the Student List and Favourite Students pages without reloading the browser.

## Features

- View all students
- Add students to favourites
- Prevent duplicate favourites
- View favourite students
- Remove students from favourites
- Global state management using Context API
- Client-side navigation using React Router
- Dynamic rendering using JavaScript `map()`
- Empty state when no favourite students are available
- Responsive user interface
- Tailwind CSS styling
